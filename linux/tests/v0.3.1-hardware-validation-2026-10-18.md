# v0.3.1 hardware validation (2026-10-18)

Board: M5Stamp ESP32-P4 + C6 (SDIO), P4 USB Serial/JTAG on COM10.  Only the
P4 flash was written; the C6 was not touched.

v0.3.1 is v0.3.0 with the CRLF `main.sh` fix (1d8cc22, #34): `autorun.sh`
strips CR from the staged scripts again.  The kernel source, the DTB and the
config are those of v0.3.0.  The checks of the fix itself are in
`v0.3.0-feature-checks-2026-10-18.md`.

## Results

The STA settings and the m5 password were written into the live drive
image from the serial console, as in the earlier records.

| Check | Result |
|---|---|
| `check-boot-log.py` after the flash | 11/11; `ES_AUTORUN STAGED`; `boot commit: written to flash`; factory SoftAP started |
| config.txt (STA) and credentials.txt written into the live drive | joined the AP without a reboot; SSH login as `m5` OK |
| `/sys/devices/system/cpu/online` | `0` (`maxcpus=1` in `/proc/cmdline`) |
| `nslookup speedtest.tele2.net` as `m5` | resolved |
| Wi-Fi under load | 5 × 10 MB `wget` over STA, all exit 0 (52–68 s each); 300 pings from the PC during the downloads, 300 answered (5–332 ms, average 92 ms); `carrier_changes` 0 |
| `dmesg` | no `WARNING` |
| `main.sh` with CRLF line ends saved to the live drive | started as `m5` at nice 10 (`SN`); `main.sh start m5`, then its output in `/run/autorun.log` |
| 3 resets with that `main.sh` on the drive | 11/11 each; `boot selection: generation=3 slot=1 crc=6f5d49ce` each; `autorun: started main.sh` and its output each time; SSH login OK |
| `cmdcheck.py` (as in `v0.3.0-hardware-validation-2026-10-18.md`) | `vi`, `less`, `top` in a pty and the everyday commands OK; `python3` with `platform.platform()` OK (the script's `os.uname()` case fails on MicroPython, as documented); `ping 8.8.8.8` alive; `traceroute -n -m 3 8.8.8.8` as root printed the hops |
| Remove `main.sh` from the drive | `not running`; `config.txt` md5 back to its value before the test |

`hostname` prints `(none)` after the resets because the `config.txt` used
for the test has no `hostname=` line; the factory `config.txt` has
`hostname=stamp-p4` and the first boot used it.
