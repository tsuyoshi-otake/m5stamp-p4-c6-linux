# v0.2.1 Stamp-P4 hardware validation

Date: 2026-09-08

Target: M5Stamp-P4 revision v1.3 on the EasyStick Stamp-P4 carrier

Serial interface: COM10, ESP-ROM USB Serial/JTAG (`303a:1001`)

The release candidate was written with `flash-candidate.ps1`. The script
verified the partition table, boot shim, kernel, rootfs, DTB, and slot 0 after
writing, then erased both A/B metadata sectors and reset the board.

Observed acceptance results:

- Linux 6.18.35 booted from the C68 handoff with an SMP-capable kernel.
- The C6 SDIO path produced `wlan0`, associated, and configured IPv4.
- The USB mass-storage LUN reported `host-owned`; a simulated host SCSI eject
  through `forced_eject` changed it to `device-owned`; reattach returned it to
  `host-owned`.
- `easystick-boot-commit` staged the exact 262144-byte FAT image in PSRAM and
  reported CRC32 `0823a082`.
- The boot shim wrote and read back inactive slot 1, committed generation 1,
  selected slot 1, and booted Linux again.
- `abtest.txt` contained `v0.2.1-ab` after a second reset, confirming that the
  updated FAT image came back from flash rather than volatile PSRAM state.

The shipped boot configuration retains `maxcpus=1`, so one Linux hart is online
while the second hart remains in the established C68 wait path.
