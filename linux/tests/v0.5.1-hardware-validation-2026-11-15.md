# v0.5.1 hardware validation (2026-11-15)

Board: M5Stamp ESP32-P4 + C6 (SDIO), P4 USB Serial/JTAG on COM10.  Only the
P4 flash was written; the C6 was not touched.

v0.5.1 is v0.5.0 with the fixes found while porting to the M5Stack Tab5:
the SoftAP did not transmit because the ESP-Hosted-NG driver was built
without AP mode (Linux 6.15+ kbuild ignores `EXTRA_CFLAGS`; e696711), and
Dropbear could crash right after authentication or drop a PTY session
(#53; patches 0012-0014, 7d21d4c).  The release build sets
`NOMMU_POOL_BESTFIT=1`, `NOMMU_USER_RESERVE=1` and `NOMMU_SYSTEM_MARK=1`
through `linux/release-build.sh`.

  SoftAP with a new SSID and passphrase) was not repeated on this image.
- The USB drive, the 30-minute soak, Deep Sleep and the #54 crash
  scenario were not repeated on the CI image.  The USB drive was checked on
  2026-11-14 with a local build of the same Dropbear and driver changes (a
  file written from the PC survived a power cycle).
