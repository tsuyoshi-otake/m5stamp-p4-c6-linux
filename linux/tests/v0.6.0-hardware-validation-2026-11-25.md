# v0.6.0 hardware validation (2026-11-25)

Board: M5Stamp ESP32-P4 + C6 (SDIO), P4 USB Serial/JTAG on COM10.  Only the
P4 flash was written; the C6 was not touched.  The board's USB drive was
kept, so it booted with its own settings: the default SoftAP
(`wifi_mode=ap`).

v0.6.0 is `main` at e61ac35, 322 commits after v0.5.1, almost all of them
merged from the M5Stack Tab5 port (issue numbers below are the
[m5stack-tab5-linux](https://github.com/tsuyoshi-otake/m5stack-tab5-linux/issues)
ones): the `m5-config` settings menu (Tab5 #42), the boot FAT guard
(Tab5 #43), the wait for a pending drive save before a reset (Tab5 #42),
the C6 link watch and the ESP-Hosted teardown fixes (Tab5 #41), the ttyGS1
recommit after a USB bus reset (Tab5 #45), the ESP-Hosted command matching
(`0049`) and the single SIGTERM for `wpa_supplicant` that make a live
SoftAP -> station switch work, and `flash-candidate.ps1`'s board check
(Tab5 #23).  The release build sets `NOMMU_POOL_BESTFIT=1`,
`NOMMU_USER_RESERVE=1` and `NOMMU_SYSTEM_MARK=1` through
`linux/release-build.sh`.

## Not covered

- The 16 MB image was not flashed, so a blank-drive first boot (default
  SoftAP with a new SSID and passphrase) was not repeated on this image; it
  would have replaced the board's drive.
- The station mode was checked only against an SSID that does not exist
  (the board has no stored router settings); a lease and NTP in station
  mode were checked on the Tab5 v0.7.0 image built from the same shared
  scripts and driver (`m5stack-tab5-linux`
  `linux/tests/v0.7.0-hardware-validation-2026-11-25.md`).
- The `m5-config` menu itself, the USB drive, Deep Sleep, the LP core
  program, a cold power-on and a C6 restart were not repeated on this
  image.
- `flash-candidate.ps1` was started from a PowerShell prompt-style
  `-Command "& .\flash-candidate.ps1 ..."` with `-PythonPath` naming the
  Python that has esptool: on this PC `python` is the Windows Store stub,
  so the default stopped at the esptool version check before writing
  anything.  Started as `powershell -File flash-candidate.ps1` (Windows
  PowerShell 5.1), the script leaves `-ArtifactsDirectory` empty (the
  `$PSScriptRoot` default of an advanced script), as recorded for Tab5
  v0.7.0; run it from a prompt, from `pwsh`, or with
  `-ArtifactsDirectory <folder>`.
