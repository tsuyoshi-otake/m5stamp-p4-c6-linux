## Fixed while validating

Found on hardware between the first v0.2.2 CI build (run 38711834169, not
published) and this one:

- **SSH commands ended in "Bad packet length"** (58d11d3): Dropbear's vfork
  child cleared the server's LinuxThreads SIGCHLD handler; the server then
  jumped to address 0 when the command exited.  See
  `linux/m3/dropbear-patches/README.md`.
- **A wrong PSK was reported as DHCP_FAILED, and CONNECTED was never written**
  (e7c9d9e): S40network now waits for operstate `up`; the udhcpc hook was
  committed 0644 and read the wrong config.  `tests/static-check.sh` now
  fails on non-executable overlay scripts.
- **Only two SSH connections a minute** (333f379): `nowait.3` in inetd.conf is
  a per-minute limit in BusyBox inetd, not a concurrency cap.
- **ENOMEM for ordinary commands** (#23): `vm.min_free_kbytes` 4096 -> 1024
  (8bc0265), a second 4 MB nommu pool region (7326587), and an `/etc/profile`
  that does not exec `id` (8221c25).  Before these, the console printed
  `Allocation of length 507904 ... failed` during boot and STA bring-up,
  SSH key installs failed, and an `S40network restart` could not start
  wpa_supplicant (1.79 MB).
- **SDIO at 5 MHz by default** (58234e2, #21).
