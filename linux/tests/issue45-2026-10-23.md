# #45 — resident BusyBox shrink: dedicated busybox-udhcpc (2026-10-23)

Issue #45: resident processes that pin the ~490 KB full BusyBox image each
hold a large NOMMU pool chunk forever.  Split the two cheapest wins out of
the full image; keep scripts and interactive shells unchanged.

Scope after the mid-task reorder (devin-task-55.md): `i45` lands **udhcpc
only**.  The `busybox-sh` script shell was built and measured (numbers
below) but its commits live on branch `i45-sh` for after #47.

## What changed on i45

- `package/busybox-udhcpc/` — a third-purpose minimal BusyBox (same
  1.37.0 source and patch set as the main package; `allnoconfig` + the
  udhcpc applet list).  `oldconfig` parity is enforced by the .mk.
- `m3-lab/busybox.fragment` — `# CONFIG_UDHCPC is not set`, so
  `/sbin/udhcpc` has a single owner.
- `m3-lab/post-build.sh` — `/sbin/udhcpc -> ../bin/busybox-udhcpc`.
- `build-m1.sh` — enables `BR2_PACKAGE_BUSYBOX_UDHCPC` for m3-lab and
  fails the build if the link does not resolve to the dedicated binary
  (suffix match: the link is relative).
- `boot-shim/main/main.c` — the `mtd-rom` DT window is now rounded up to
  a power of two.  `physmap` sizes the MTD as `BIT(fls64(reg_size)-1)`:
  the 7 MiB partition reg produced only a **4 MiB** `mtdblock0`, so any
  rootfs larger than 4 MiB (this work pushed it to ~4.26 MB) could not be
  mounted — a hard panic loop.  The window is now 8 MiB; the tail only
  exposes following flash, read-only.

## busybox-sh experiment notes (i45-sh)

Three config corrections were needed before scripts ran cleanly —
`HUSH_TICK` is *command substitution* (`` ` `` and `$( )`, not a ticker),
`FEATURE_SH_MATH*` backs `$(( ))`, and the parser/builtin set
(IF/LOOPS/CASE/FUNCTIONS/LOCAL/…) is what `#!/bin/sh` actually needs.
Interactive knobs (INTERACTIVE/SAVEHISTORY/JOB) stay off; logins run
`/bin/hush` on the full image.  With those, init scripts run error-free
and idle measured as above.
