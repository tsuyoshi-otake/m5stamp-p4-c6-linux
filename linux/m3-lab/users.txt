# Deliberate M5Stack first-boot account for the image.
# No built-in password (#11): `*` disables password login until
# S05tmpfs applies password= from credentials.txt on the USB drive
# (generated per device on first boot, #24/#30).  `*`, unlike `!`, still lets
# Dropbear accept authorized_keys.  `passwd` does not persist on the
# read-only rootfs.
# root (#37): the image shadow keeps `root:!` (post-build.sh); at boot
# root_password= from credentials.txt is hashed into the runtime shadow for
# `su`, and the drive's root_authorized_keys installs to /root/.ssh so
# Dropbear accepts root by key only (`-g` in inetd.conf).
